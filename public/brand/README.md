# Canwoo brand assets

The current fan is original vector artwork generated by `scripts/build-brand.mjs`. The display, header and login fan have eleven folds and ten internal ribs, excluding the two guard sticks. The tiny browser icon retains a nine-fold, eight-rib optical variant. Both brand wordmarks are SVG geometry and do not require font requests. The Latin wordmark uses Google Sans Flex glyph outlines for lowercase `canwoo`, stored in `lib/brand-latin.json`; the Chinese wordmark uses Qiji outlines for 參伍, stored in `lib/brand-han.json`. Both are rendered by `components/canwoo-brand.tsx`.

- `canwoo-mark.svg`: transparent gold-paper display fan.
- `canwoo-wordmark.svg`: transparent lowercase `canwoo` lettering from Google Sans Flex, with `wght=460`, `opsz=48`, `ROND=20`, `wdth=100`, `GRAD=0`, and `slnt=0`. The moderately light weight and subtly softened terminals preserve a restrained sans-serif appearance. Copyright 2015 Google LLC. All Rights Reserved; source font under SIL OFL 1.1, retained in `GoogleSans-OFL.txt`. [Official versioned font asset](https://fonts.gstatic.com/s/googlesansflex/v22/t5t7IQcYNIWbFgDgAAzZ34auoVyXipusfhcat2c.ttf). `scripts/build-latin-wordmark.py` takes the local full variable TTF, verifies its SHA-256, and uses fontTools and uharfbuzz to generate the SVG and shared path data. Native HarfBuzz kerning is preserved; the complete word is scaled uniformly, without stretching individual letters.
- `Newsreader-OFL.txt`: retained attribution and license for the earlier Newsreader Latin artwork. The current Latin wordmark uses Google Sans Flex.
- `canwoo-han-wordmark.svg`: transparent 參伍 lettering from Qiji. Copyright 2020 Lingdong Huang; source font under SIL OFL 1.1, retained in `Qiji-OFL.txt`. The source is the `qiji.ttf` asset from [release 0.0.4](https://github.com/LingDong-/qiji-font/releases/tag/0.0.4). `scripts/build-han-wordmark.py` uses fontTools and a local copy of that TTF, checks its SHA-256, and generates the SVG and shared path data. Each glyph outline is uniformly scaled and optically positioned; the site does not load the full font.
- `MaShanZheng-OFL.txt`: retained attribution and license for the previously distributed Ma Shan Zheng 参伍 lettering. The current Chinese wordmark uses Qiji.
- Noto Sans SC: the previously used self-hosted two-character weight-600 subset `canwoo-han-sans.ttf` remains for cached clients. SIL OFL 1.1, see `NotoSansSC-OFL.txt` and https://github.com/google/fonts/tree/main/ofl/notosanssc.
- Geist: interface type, bundled by next/font at build time. SIL OFL 1.1, see `Geist-OFL.txt` and https://github.com/google/fonts/tree/main/ofl/geist.

Earlier Google Sans Flex, Manrope and Noto Serif assets remain for cached clients with their original licenses. Current brand styles no longer request the Latin font subsets. Typeface attribution does not imply any brand affiliation. See `docs/cw-brand.md` for design rationale and validation.

`history-canal.webp` is an original AI-generated decorative illustration, not a historical source or reproduction. See docs/history-background.md for its generation prompt and intended use.
