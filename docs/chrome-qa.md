- 长笔记限制编辑区和阅读预览高度，并保留底部操作区；内容再长也可以找到保存和导出。
- 手机端笔记弹窗允许按钮换行，修复英文界面的横向溢出；实测弹窗内容宽度与可用宽度均为 358 px。
- 切换至账号设置或其它页面时收起手机导航。
- 显式切换的界面语言刷新后保留，不被账号默认语言覆盖。
- 研究计划的成员列表包含项目负责人，流程图、分工和步骤详情显示姓名，避免显示内部账号 ID。任务详情元数据布局压缩，原文与核查内容位置更靠前。
- 修复步骤详情两个子组件使用同一 React key 的渲染错误；重新打开步骤后没有新增该错误。
- 写作工具生成的出处链接使用当前请求站点，修复本地或预览环境引用误跳生产站的问题。
