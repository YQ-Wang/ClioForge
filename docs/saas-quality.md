### Reading continuity, shared costs and batch transcription — 2026-09-05

Single-page transcription, immediate analysis and queued analysis now share the existing project budget. Migration 0010 adds an idempotent direct-call cost ledger. Requests reserve conservatively before invocation, settle successful known usage, retain uncertain reservations, and never retry paid calls automatically. A scheduled recovery marks stalled calls for attention. Older calls are not assigned invented historical costs. Custom model rates and an OCR/analysis default are configurable in account settings. The reservation is an estimate control, not a provider invoice cap; image reservations can substantially exceed final token-based cost. Budget rejection now states the reservation required.

Batch transcription processes up to ten selected pages sequentially while the page stays open. Each result persists separately for review; completed candidates are reused in the browser and server. Closing stops subsequent pages after the in-flight request. Failures stop the remaining batch; resuming is explicit. This is not an unattended durable OCR queue. Provider truncation preserves a warning/partial result and prevents a background research result from progressing as complete.

Task inbox notifications no longer display raw truncated JSON. Full candidate reports show prose and source quotations, with safe fallback for malformed responses. Model-authored claims of having passed checks are discarded during display parsing; only the actual reviewed research workflow establishes check status.
