# Canwoo gold-paper fan mark

The current mark takes its visual direction from a restrained Ming-style gold-paper folding fan. Eleven narrow paper folds share a continuous 128-degree crown and a concentric inner hem. Fine exposed ribs meet at one compact pivot. The outer guard sticks belong to the fan structure; there is no separately drawn W or forced C. This is an original vector design, not a traced artifact or third-party logo.

The shared mark uses inherited ink with two flat opacity levels. Light surfaces use #9c7d3e; dark surfaces use #d2ba82. There are no gradients, textures, shadows or simulated metallic effects. A nine-fold optical variant with wider gaps is used in the browser/app icons so the fan remains legible at 16px.

The wordmark keeps the self-hosted Google Sans subset at weight 500 and Noto Sans SC at weight 600. The interface uses Geist. Font license files remain with the assets; no third-party logo lettering or artwork is included.

- `components/canwoo-brand.tsx`: shared inline mark and bilingual lockup.
- `app/brand.css`: theme colors and wordmark sizing.
- `public/brand/canwoo-mark.svg`: transparent, reusable main mark.
- `public/icon.svg` and `public/favicon.svg`: identical compact app icons.
- `app/layout.tsx`: favicon cache revision `goldfan3`.
- `work/fan-refined/`: geometry generator, size explorations, outlined lockup and visual validation.

The archived `work/fan-mark/` and `work/brand-soft/` folders document earlier designs; they are not the current production artwork.
