# 项目协作

在项目页点击 **成员与邀请**。负责人输入对方的邮箱，选择“仅阅读”“协作编辑”或“协作并复核”，创建邀请后将链接发给对方。这里不会自动发送邮件。

对方无需提前注册。她使用受邀邮箱登录或注册并验证邮箱后，会在“我的研究”看到邀请；点击“接受并打开项目”后才获得访问权限。链接不能让其它邮箱加入。邀请 7 天有效，负责人可以撤销，或者用同一邮箱重新创建；重新创建会使旧链接失效。

| 权限       | 可以做什么                                             |
| ---------- | ------------------------------------------------------ |
| 仅阅读     | 阅读、查看版本和下载项目资料                           |
| 协作编辑   | 还可导入材料、校订文字、保存笔记与摘录、讨论和开展分析 |
| 协作并复核 | 还可复核、采纳研究结果                                 |
| 项目负责人 | 以上全部，以及邀请、修改权限、撤销邀请和移除成员       |

负责人在成员旁直接调整权限。移除成员需要确认；移除后新的项目数据请求会被拒绝，旧邀请不能重新取得访问权。已经添加的材料、笔记与核查记录保留，已经下载的副本无法收回。页面恢复焦点或刷新时会重新检查当前权限。

模型密钥和 Google Drive 连接仍属于各自账户，不会因为加入项目而分享。模型任务执行前重新检查写入权限；已经发往服务商的调用无法保证撤回。
